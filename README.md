# Sahil Chauhan | Data Analyst Portfolio

Personal portfolio website of Sahil Chauhan, a B.Tech graduate in Artificial Intelligence from Nagpur, India, looking for Data Analyst roles.

**Live site:** https://chauhansahiil.github.io/portfolio/

## About the site
A single-page portfolio that presents my work, experience and skills in one place, with animated backgrounds, scroll transitions and an AI assistant that answers questions about me.

## Sections
- **About:** who I am and what I'm looking for
- **Experience:** three internships, shown on a timeline that draws itself as you scroll
  - Full Stack Developer Intern, Tenet Computer and Communication
  - Data Analyst Intern, KultureHire
  - Python Programming Intern, CodeSoft
- **Projects:**
  - Customer Trends Analysis using SQL, Python and Power BI
  - Secure Banking System Using Blockchain Technology
- **Skills:** data analysis, ML and AI, cloud, databases and programming
- **Certifications:** Accenture, IBM, NVIDIA and Indian Blockchain Institute
- **Education:** B.Tech in Artificial Intelligence and coursework
- **Contact:** a validated form that sends messages to my inbox, plus my email and social links

## Highlights
- AI assistant (press Ctrl+K) that answers questions about my projects, skills, education and resume
- Cursor-reactive background, scroll animations and hover effects
- Responsive layout for phones, tablets and desktops

## Built with
HTML, CSS, JavaScript, jQuery, Typed.js and Cloudflare Workers
